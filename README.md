# 墨痕武道：水墨火柴人 (Ink Martial: Stickman Roguelike)

一款具有浓郁中国古典水墨美学风格的**仿3D火柴人动作肉鸽战斗游戏**。游戏支持键鼠操作与触屏手势识别，独创"**指哪打哪 · 全屏跟手瞬杀**"与"**水墨书法手势连斩**"交互系统，融合了骨骼动画打击感、敌人受击硬直（破势）机制与多重肉鸽技能词条随机组合。

---

## 游戏核心特性

1. **水墨书法手势与指哪打哪战斗体系**：
   - **全屏跟手位移**：手指在屏幕上滑动，火柴人以极高响应速度紧随指尖移动，留下水墨残影与墨迹尘烟。
   - **到达自动拔剑斩击**：手指离开屏幕瞬间，角色到达终点并自动拔剑释放凌厉斩击（智能索敌面朝最近敌人）。
   - **多目标划敌瞬杀连击**：一笔划过多个敌人，自动触发高速穿梭闪避斩击，空中爆发朱砂与焦墨交织的**剑意连接特效（Slash Links）**与古印章篆刻。
   - **空中千斤坠**：从空中滑步落地时自动触发震撼地面的下砸冲击波。
   - **书法招式识别**：书写『一』字横扫千军、竖劈力劈华山、挑空飞燕凌空、画圆浑元太极盾、折线踏影瞬杀。

2. **敌人受击硬直机制（破势与定身）**：
   - 击中敌人强制打断其前摇与蓄力攻击；
   - 产生 0.45s ~ 0.75s 受击硬直（伴随身体后仰、墨迹高频震颤与『⚡破势』提示），重置攻击冷却；
   - Boss 首领具备武道宗师韧性，需连击破势。

3. **攻击前摇预警系统（新增）**：
   - 所有近战敌人出手前头顶亮起红色「！」并后坐蓄力（0.4s~0.6s）；
   - 蓄力期间挥剑命中即可**打断攻击**——将「破势」从奖励机制升级为反制博弈核心。

4. **Boss 专属技能组（新增）**：
   - **震岳一击**：地面红圈预警（0.9s），走位躲开判定圈即可反制；
   - **墨珠散射**：五连暗紫墨珠扇形弹幕；
   - **墨卒护法**：半血后解锁召唤援军；
   - **狂暴化**：血量低于 50% 进入二阶段，移速攻速大增并附红雾特效。

5. **精英词缀系统（新增）**：
   - 第三折起随机出现精锐（每波至多 2 名），带彩色光环与顶标；
   - **迅捷**（移速+45%）、**铁壁**（血量+90%，大幅抗击退）、**狂暴**（伤害+50%，攻速+45%）、**汲影**（攻击吸血）；
   - 斩杀精英获额外功绩与墨意。

6. **妖墨阵容扩充（新增）**：
   - **爆墨傀儡**（第五折起）：焦褐圆肚高速冲锋，贴近后点燃引信自爆——引信期（头顶亮「爆」）击杀可「拆除」获额外功绩且不引爆；爆炸敌我不分，可诱其炸入妖墨阵中借刀杀人；
   - **墨盾武僧**（第六折起）：铁灰武僧正面持盾，正面格挡 80% 伤害——正面硬打仅两成透伤可缓慢磨血（多打几盾也能击破，不影响通关进度），绕背攻击全额、趁其收盾出招的前摇窗口、或受击硬直中破防效率更高；武僧转身迟缓（0.55s），踏影瞬杀穿身后是绝佳破防手段；
   - **符笔妖道**（第八折起，同屏至多一位）：墨绿道袍远端游走施法——「妖符·唤」召唤墨卒护法，或扇形三连**追踪符珠**（有限转向率，可走位甩开），威胁极高宜优先狙杀；
   - **飞白鹤**（第九折起，同屏至多两只）：靛青白鹤高空盘旋（普通招式够不到），头顶亮「袭」后锁定玩家位置俯冲穿刺——走位躲开落点，趁落地喘息窗口输出，或用「挑」招将其击落；
   - **砚台龟**（第十折起，同屏至多一位）：背负砚台墨甲的坦克，龟甲竖起时受击会**反震 22% 伤害**——趁其头顶亮「震」伸头出招的前摇窗口猛攻，觉醒技/反伤词条亦可克制；
   - **醉墨剑客**（第十一折起）：酒褐剑客醉步摇摆逼近，挥击有 35% 概率被「醉避」侧身闪开——趁其头顶亮「斩」出招后或连斩后「醉倒」踉跄时全力输出；
   - 新增第九/十/十一折专属波次：**鹤啼墨空 / 砚甲横江 / 醉剑狂歌**；生成器加权池已解锁十一系妖墨（近战/远程/重击/背刺/自爆/格挡/召唤/对空/反震/闪避/宗师），机制互补构筑博弈深度。

7. **肉鸽词条系统（12 → 26 种）**：
   - 修复四个原本声明未生效的效果（暴击墨爆、暴击伤害、手势加成、寒缓），全部真实接线；
   - 新增八种流派：**凝墨为甲**（波次墨盾）、**雷引连枝**（击杀连锁闪电）、**朱砂焚意**（灼烧持续伤害）、**判官笔锋**（斩杀线处决）、**残页·续墨**（一次复活）、**铁画银钩**（反伤）、**胸藏万墨**（墨意上限与暴击回墨）、**掠影无踪**（滑步风刃）；
   - 觉醒与新敌对策六词条：**鹤啼九天**（对浮空妖敌增伤35%）、**醉墨行**（12% 完全闪避）、**墨魂涌动**（觉醒充能+30%）、**万墨归一**（觉醒伤害+60%）、**气吞山河**（觉醒范围+50%）、**玄武镇岳**（每波开战觉醒充能+50）；
   - 抽卡按稀有度加权，波次越深绝品概率越高；每波可「重新推演」一次。

8. **进程与目标（新增）**：
   - **通关目标**：历经十五折击败「墨煞大帝 · 终折」达成「墨武大成」；
   - **无尽模式**：胜利后可继续挑战无限妖墨深渊；
   - **江湖行录**：localStorage 持久保存最高功绩、最远折数、累计斩敌、问鼎次数，主菜单随时查看；
   - 结算界面完整统计：斩敌数、最大连击、精锐/宗师击杀、闯荡时长、本局词条录、破纪录徽章。

9. **战斗反馈增强（新增）**：
   - 连击加成计分（每连击 +2% 功绩，上限翻倍）与波次通关奖励；
   - 波次开场书法大字横幅（Boss 波红字警示）+ Boss 顶部大血条（狂暴态变化）；
   - 低血量红色脉动边缘 + 心跳音效；受击屏幕红闪；击杀回复、调息回气浮字。

10. **特效体验全面升级（新增）**：
   - **笔刷剑弧**：六大手势招式各配专属水墨挥砍轨迹——刺（锐利突刺）、横（起笔重收笔轻的宽弧）、劈（自上而下重劈）、挑（逆挑上勾）、圆（旋转双环太极墨劲）、闪（横向残风波），全部带「枯笔飞白」碎墨与金芒挑锋，分段变宽笔触模拟毛笔提按；
   - **水墨留痕**：击杀溅墨、暴击朱砂溅地、力劈地裂——地面墨渍与裂纹缓慢晕开淡出，越战越有「血染宣纸」的临场感；
   - **冲击激波环**：太极震退、力劈落地、Boss 震岳、狂暴变身、复活与通关时地面扩散双层墨劲环；
   - **电影化慢动作**：Boss 陨落（0.8s）、收波最后一杀（0.42s）、残页复活（0.55s）触发 0.3x 时间流速，伴随上下渐变墨帘压边与内缘金线；

   - **屏缘泼墨**：连击高光、Boss 变身、通关时刻四角墨笔晕点 + 边缘墨晕闪烁；
   - **死亡墨魂**：敌人被斩后化为升腾摇曳的墨魂消散（Boss 赤墨、精英随词缀色）；
   - **粒子形态学**：墨滴按速度方向拉伸成运动模糊拖尾、冲刺速度线、弹道尾迹（剑气/墨珠/雷链/震波/墨箭各有专属粒子）、跑步扬尘、飘落墨瓣氛围；

   - **墨龙冲击波**：地面震波重构为锯齿浪峰（双层正弦扰动）+ 涌动墨芯；
   - **伤害数字弹跳**：暴击与招式文字带回弹超射入场动画；
   - **性能护栏**：粒子池上限 460、墨渍/剑弧/激波环各自容量控制，低端设备不掉帧。

11. **工程体验（新增）**：

## 快速启动运行指南

### 环境要求
- Node.js 18.0 或更高版本
- npm / pnpm / yarn / bun

### 1. 安装依赖
```bash
npm install
```

### 2. 本地开发运行
```bash
npm run dev
```
启动后在浏览器打开控制台输出的地址（默认 `http://localhost:3000`）即可开始游玩。

### 3. 项目打包构建
```bash
npm run build
```
构建产物将输出在 `dist/` 目录中。

## 操作指南

### 触屏操作（移动端/平板）：
- **全屏挥墨模式（推荐）**：
  - 手指在屏幕上滑动：角色极致跟手移动，松手瞬间自动拔剑斩击；
  - 划过敌人：触发【瞬杀连斩】，目标间呈现水墨连击锁链；
  - 轻点空地：施展【踏雪寻梅】身法位移；
  - 画出特定轨迹：释放太极盾、裂地斩、挑空击等书法招式；
  - 敌人头顶出现红色「！」时，滑步走位或打断其蓄力。
- **分屏双控模式**：
  - 左半屏：拖动摇杆控制走位与起跃；
  - 右半屏：挥动画笔书写招式。

### 键盘操作（PC端）：
- **移动**：`W`（向深处走）、`S`（向镜头走）、`A`（向左跑）、`D`（向右跑）
- **起跃轻功**：`空格键 (Space)` 或 `K`
- **暂停**：`ESC`
- **书法武学快捷键**：
  - `J`：墨刺连击
  - `U`：横扫千军（释放穿透剑气）
  - `I`：力劈华山（大地震颤地刺）
  - `O`：浑元太极（太极八卦反弹护盾）
  - `L`：踏影瞬杀（疾速穿梭斩击）
- **觉醒技**：`G` —— 觉醒槽满后释放「万墨归宗」全屏墨爆（也可点 HUD「觉」按钮）

## 性能优化（v3）
- **离屏静态图层缓存**：宣纸底色渐变、暖墨暗角、受击红晕、低血红晕、屏缘泼墨（含四角晕点）、慢动作上下墨帘全部预烘焙为离屏 Canvas，每帧仅 `drawImage` 一次（受击/低血用 `globalAlpha` 实时调制强度），消除每帧的渐变重建与全屏径向填充；窗口 resize / DPR 变化时自动作废重建
- **地面渐变缓存**：宣纸地面 `CanvasGradient` 只在尺寸变化时重建
- **零分配热路径**：粒子/弹道/敌人/浮字/剑弧/墨渍/激波环/残影/预警圈全部改为原地压实（in-place compaction），取代每帧 `filter()` 产生的新数组；渲染投影改用共享 scratch（`projectXYZ`），粒子渲染内联投影数学，单帧零对象分配
- **屏幕外剔除**：敌人（±150px）/弹道（±90px）/残影/粒子/浮字/墨渍/激波环/剑弧出屏即跳过，镜头远处的敌群不再消耗骨架绘制
- **shadowBlur 清零**：浮动战斗数字、前摇「！」、破势标记改用宣纸色 `strokeText` 描边（视觉等效，开销大幅降低）
- **逐帧数学提升**：击退阻尼、墨魂阻尼等 `Math.pow` 每帧计算一次；`performance.now()` 每帧缓存
- **自适应画质**：帧耗时 EMA 每 2s 判定一次（>24ms 降一档、>33ms 直降最低档，只降不升防震荡），逐级下调粒子上限 460→280→150、环境飘墨 26→16→8、弹道尾迹概率 0.62→0.28，标签页切回的大帧间隔不纳入统计
- **实测数据**（1920×1080，22 敌 + 460 粒子 + 14 剑弧 + 26 墨渍 + 20 浮字同时渲染）：`render()` 平均 1.06ms、`update()` 平均 0.09ms，理论帧余量 >700fps；实际战斗 60fps（vsync 上限），全程控制台零报错

## 性能优化（v4 · 防卡死专项）
- **引擎生命周期 destroy()**：新增 `destroy()` 方法（停止循环 + 移除全部 window/document/canvas 事件监听），React 卸载时调用——修复旧引擎僵尸监听器永久持有整局世界状态的内存泄漏（长时间反复开局在移动端可累积至 OOM 卡死）
- **同屏妖墨上限**：生成器加拥挤保护——存活妖墨达 22 只时推迟生成（不消耗波次配额，0.75s 后重试；Boss 本体豁免），无尽模式清怪速度跟不上生成速度时敌人不再无界堆积压垮帧率
- **无尽波次软上限**：单波敌人数封顶 42 只，后期压力靠妖墨构成（自爆/格挡/召唤）而非无界数量
- **暂停渲染冻结**：暂停/结算画面世界静止，仅在脏标记（暂停切换/resize/画质降档/重开）时重绘一帧——实测暂停 3 秒 `drawImage` 调用为 0（优化前为 ~180 次全量重绘），消除移动端挂机暂停的持续发热与热降频卡顿
- **移动端切后台保护**：新增 `visibilitychange` 监听（iOS Safari 切后台常不触发 blur）——隐藏时自动暂停 + 释放触点，回前台重置时间基准（防大帧跳变）并唤醒 AudioContext
- **音频零分配**：笔触/挥剑的噪声声源改用预生成共享白噪声缓冲池（4×0.5s，AudioBuffer 不可变可并发播放），滑砍时不再每次调用都新建并逐样本填充 AudioBuffer（原每秒可达 20-30 次分配）
- **BGM 生命周期**：暂停/返回标题/卸载时停止古琴循环定时器（防后台空转耗电），恢复游戏自动续播；静音开局后解除静音 BGM 可自动恢复
- **长笔迹保护**：手势笔迹超 320 点自动淘汰最旧四分之一，超长拖拽不再无界累积内存与识别耗时
- **实测数据**（headless Chromium 软渲染）：战斗中 42fps（同环境标题界面基准 26fps，战斗渲染预算显著优于静态页）；暂停 3s 渲染调用 0 次；完整会话（战斗 + 两次暂停/恢复循环 + 死亡结算 + 重开）JS 堆稳定在 3.8MB 零增长；击杀→计分→波次计数联动验证通过；全程控制台零报错

## 项目技术栈
- **框架**：React 19 + TypeScript + Vite
- **动画与样式**：Tailwind CSS + Lucide Icons + Procedural Canvas 2D
- **音效合成**：Web Audio API 自研水墨古筝与打击声效合成器（Master GainNode 音量总线）
- **骨骼与物理引擎**：自研轻量级伪3D正交透视物理与动力学骨骼算法
- **进程持久化**：localStorage 江湖行录
